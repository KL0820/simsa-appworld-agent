# Evaluation

Historical thesis results and the recent smoke test are different experiments.
The full result is 96/168 tasks, not a projection from a small smoke sample.
The 56-task ablations use variant `_2`; scenario goal completion (SGC) requires
all three variants of each scenario and is not reported for the smoke.

## Comparison protocol

- Historical reference: `test_normal_168_visgap_from4/20260705_060159_211523`,
  run from the `vis-gap-apitrace` worktree.
- Five tasks fixed before the completed run: the existing three `quick_smoke`
  tasks, plus the first two remaining `_2` task IDs in lexical order.
- Historical results did not determine selection of the additional two tasks.
  The original three smoke tasks were already selected for stable success;
  this sample is not representative of overall benchmark accuracy.
- `configs/portfolio_smoke.json` is reconstructed from the historical resolved
  configuration. Its skill-library path was normalized from a machine-local
  absolute path to a repository-relative path. For `fd1f8fa_2` alone, the
  historical resolved LLM call timeout was 300 seconds while this batch used
  150 seconds; its latency and token change are therefore not an exact-setting
  comparison.
- Same Gemini model alias and sampling parameters; model service and SDK versions
  may have changed. This is a historical comparison, not a same-day controlled A/B.
- Recorded calls/tokens are the existing subagent aggregates, not full billing
  totals; skill selection and final-answer extraction/retries are not fully included.

## Five-task smoke, 2026-10-01

Five tasks were attempted. Four reached AppWorld evaluation and passed every
check; the fifth (`042a9fc_2`) was interrupted before evaluation. The batch
tool prints "4/5 (80.0%)", but this is a completed-and-passed count over
attempts, **not** a measured success rate over five evaluated tasks.

| Task | Historical evaluator | Recent evaluator | Historical wall | Recent wall | Historical / recent recorded calls | Historical / recent recorded tokens |

| `13547f5_2` | 6/6 | 6/6 | 103.7 s | 125.0 s | 9 / 8 | 37,179 / 30,838 |
| `024c982_2` | 7/7 | 7/7 | 143.2 s | 140.4 s | 15 / 9 | 67,112 / 37,158 |
| `fd1f8fa_2` | 5/5 | 5/5 | 1,464.5 s | 682.8 s | 77 / 39 | 575,036 / 246,602 |
| `042a9fc_2` | 2/5 | Not scored: interrupted after 67 minutes | 630.9 s | More than 4,000 s | 49 / unavailable | 491,957 / unavailable |
| `09b0ee6_2` | 2/2 | 2/2 | 325.9 s | 284.6 s | 29 / 26 | 232,934 / 208,161 |

The fourth task repeatedly stalled during model-assisted execution and passed
the requested 40-minute per-task runtime budget without producing an evaluator
summary. It was manually interrupted to let the fifth task start. The batch
record reports a subprocess failure, not an AppWorld task score; its 0-second
metric is a missing summary, not the observed wall time. The third task recovered
from one recorded finder rate-limit error and passed.

Across the **four evaluated tasks**, the recent run passed 20/20 evaluator
checks, used 82 recorded subagent model calls and 522,759 recorded tokens.
These sums exclude the interrupted task's incomplete metrics, so they cannot
be compared with five-task historical totals or read as the full cost of this
attempt. Task-specific trajectories vary across runs; the four passes do not
prove that the refactor preserved overall benchmark performance.

## Validation limits

The research checkout passed 634 offline tests with one optional embedding test
skipped before the smoke. In a fresh Python 3.13 environment with AppWorld data,
the public snapshot passed **600 tests**, with **6 skips** and one ADK
deprecation warning. Five skips require the omitted source corpus; one optional
embedding test requires `sentence-transformers`. The 20 core contract tests
also passed with no AppWorld data or model credentials.

One completed task from the earlier cleanup passed 6/6 checks. It used a default
prior-milestone visibility setting different from the historical run and is not
treated as the matched five-task comparison.

## Provenance and research caveats

- The 187 released skills are byte-identical to the final experiment worktree.
- The retained 90-task source corpus labels its producer as `oracle-claude` and
  model as `human`. The author still needs to reconcile these historical labels
  with the collection procedure. Do not infer that every source trajectory was
  autonomously generated by Gemini.
- Prompt length reductions measure fixed text, not human hours, total tokens or cost.
- The single-seed results do not establish statistical equivalence or generalization.
- Raw logs, task data and source trajectories are retained separately, not included
  in the public-source snapshot. The original research history remains intact.
